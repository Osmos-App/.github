# .github

[🇬🇧 English](README.md) · [🇹🇷 Türkçe](README.tr.md)

[Osmos App](https://github.com/Osmos-App) için organizasyon genelinde geçerli topluluk ve sağlık dosyaları.

Bu dosyalar, yerel olarak geçersiz kılınmadıkça (overridden) organizasyondaki tüm repository'ler için geçerlidir.

| Dosya | Amaç |
|------|---------|
| [CONTRIBUTING.md](CONTRIBUTING.md) | Nasıl katkıda bulunulur |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Topluluk standartları |
| [SECURITY.md](SECURITY.md) | Güvenlik açıklarını bildirme |
| [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md) | PR kontrol listesi |
| [ISSUE_TEMPLATE/](ISSUE_TEMPLATE/) | Hata ve özellik şablonları |
| [SUPPORT.md](SUPPORT.md) | Destek ve iletişim kanalları |
